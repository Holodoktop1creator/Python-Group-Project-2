# Шахин FPV

3D-игра про оператора FPV-дрона. Работает в браузере на компьютере (и на телефоне),
движок Three.js, без установки.

## Запуск на компьютере

Открой `index.html` в Chrome, Edge или Firefox. Нужен интернет: движок и шрифты
грузятся с CDN. Либо выложи папку на GitHub Pages и открывай по ссылке.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / поворот | `W` `S` / `A` `D` | левый стик |
| Наклон | стрелки или мышь (ПКМ включает) | правый стик |
| Взлёт / стоп моторов | `Пробел` | A |
| Подрыв | `E` | B |
| Режим СТАБ / АКРО | `M` | X |
| Камера FPV / сзади | `C` | Y |
| Пауза | `P` / `Esc` | Start |

- **СТАБ**: дрон сам выравнивается и держит высоту. Для начала.
- **АКРО**: газ не возвращается в центр, стик задаёт скорость вращения. Как у настоящих пилотов.

## Что внутри

- Мир 2.6 × 2.6 км: холмы, поля, лес и лесополосы, река с мостом, деревня, ЛЭП с проводами.
- Физика квадрокоптера: тяга по оси дрона, сопротивление воздуха, ветер, батарея 4S с просадкой.
- Аналоговая FPV-картинка: линза «рыбий глаз», хроматика, шум, срывы строк.
- Связь: помехи растут с расстоянием и за рельефом, РЭБ глушит сигнал.
- Техника: грузовик, БТР, танк, ЗСУ, РЭБ, гаубица. ЗСУ и пулемёты стреляют трассерами.
- После удара показывается вид с дрона-разведчика с результатом.
- 4 миссии: Полигон (тренировка с кольцами), Колонна, Огневая позиция, Охота на танки.
- Настройки: качество графики, угол камеры, чувствительность, звук.

## Файлы
