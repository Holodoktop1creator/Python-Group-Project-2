# 🚁 Небесный курьер: симулятор управления беспилотником

2D-симулятор дрона-доставщика на Python и pygame. Ты оператор квадрокоптера в
процедурно сгенерированном городе: забираешь грузы на складах и доставляешь
клиентам на крыши небоскрёбов. Мешают ветер, птицы, бесполётная зона и
ограниченный заряд батареи.

## Запуск

```bash
pip install -r requirements.txt
python main.py              # случайный город
python main.py --seed 42    # фиксированный город (удобно соревноваться с друзьями)
```

Тесты: `python -m pytest`

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `↑` | набор высоты (в ручном режиме прибавить газ) |
| `S` / `↓` | снижение (в ручном режиме убавить газ) |
| `A` `D` / `←` `→` | наклон дрона влево / вправо |
| `M` | переключить **РУЧНОЙ** режим и **СТАБИЛИЗАЦИЮ** |
| `T` | автопилот (награда за миссию ×0.5) |
| `H` | подсказка |
| `P` / `Esc` | пауза |
| `R` | новая игра (в паузе или после крушения) |

## Режимы полёта

- **СТАБИЛИЗАЦИЯ** (по умолчанию): `W`/`S` задают вертикальную скорость, а газ
  подбирает PID-регулятор. Отпустил кнопки, и дрон висит на высоте.
- **РУЧНОЙ**: `W`/`S` напрямую меняют газ, как на настоящем пульте в режиме
  acro/angle. Висеть на месте придётся самому. Режим для профи.
- **АВТОПИЛОТ**: дрон сам набирает безопасную высоту, облетает здания, садится
  на площадку и сам летит на базу, если не хватает заряда. Но награда вдвое меньше.

## Правила

- Миссия: забери груз на **складе** (оранжевая площадка) и доставь **клиенту** (зелёная).
- Чтобы погрузить или сдать груз, постой на площадке ~1 секунду.
- **Мягкая посадка**: вертикальная скорость < 2.6 м/с, наклон < 18°. Жёсткая
  посадка бьёт корпус и груз. Удар быстрее 11 м/с уничтожает дрон.
- **База (H)**: заряжает батарею и чинит корпус. Пока стоишь на базе, таймер миссии не идёт.
- Груз тяжелит дрон, поэтому батарея садится быстрее.
- **Хрупкий** груз портится вдвое сильнее. Награда умножается на его целость.
- **Ветер** усиливается с высотой и с каждым уровнем (новый уровень каждые 2 доставки).
- **Птицы** отнимают 15% корпуса. В **красной зоне (аэропорт)** очки тают каждую секунду.
- Игра заканчивается, если дрон разбился или сел с пустой батареей.
- За быструю доставку дают бонус за оставшееся время.

## Как устроено

```
drone_simulator/
├── main.py                 # точка входа
├── drone_sim/
│   ├── config.py           # все константы баланса
│   ├── physics.py          # физика квадрокоптера: тяга, наклон, инерция моторов, сопротивление, батарея
│   ├── autopilot.py        # PID-регуляторы, режимы полёта, автопилот
│   ├── world.py            # город, ветер, птицы, зоны, столкновения, миссии (без pygame)
│   └── game.py             # отрисовка, HUD, миникарта, меню (pygame)
└── tests/test_simulation.py
```

Физика и игровая логика отделены от графики, поэтому весь симулятор можно
тестировать и гонять без окна. Например, проверить, что автопилот доставляет груз:

```python
from drone_sim.world import Simulation
from drone_sim.autopilot import PilotInput

sim = Simulation(seed=2)
sim.toggle_autopilot()
for _ in range(60 * 200):
    sim.step(1 / 60, PilotInput())
print(sim.deliveries, sim.score)
```

### Физическая модель

- Тяга `T = газ × 40 Н` направлена вдоль оси дрона: `Fx = T·sin(θ)`, `Fy = T·cos(θ) − m·g`.
- Моторы раскручиваются с задержкой 0.08 с, наклон ограничен 35° и скоростью 200°/с.
- Сопротивление считается относительно воздуха: `F = k·(ветер − v)`, поэтому ветер сносит дрон.
- Расход батареи: `0.12 + 1.0·газ^1.5` % в секунду.
- Ветер: постоянная часть + сумма синусоид (порывы) × коэффициент высоты.

Баланс подкручивается в `drone_sim/config.py`.
