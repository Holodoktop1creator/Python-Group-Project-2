# Шахин: ударный дрон

Мобильная 2D-игра про оператора ударного дрона. Бронеколонна идёт на базу,
ты бомбишь, пускаешь ракеты, уворачиваешься от зенитного огня и ракет ЗРК.
Один HTML-файл, без библиотек и без интернета (кроме шрифтов Google).

## Как играть на телефоне

- Открой `index.html` в Chrome на Android (или опубликованную ссылку).
- Меню Chrome → «Добавить на главный экран»: игра откроется на весь экран, как приложение.
- Держи телефон горизонтально.

## Режимы

- **Операция**: волны техники, магазин улучшений между волнами, ночные волны,
  3 дрона в запасе. Проигрыш, если база разрушена или кончились дроны.
- **Песочница**: ставь любую технику пальцем, колонну одной кнопкой, бессмертие,
  бесконечный боезапас, ночь, ветер, замедление времени, «враг стреляет»/«враг едет».

## Что есть

- 6 видов оружия: пулемёт с автонаведением, бомба с траекторией прицела, самонаводящаяся
  ракета с захватом цели, кассета на 8 суббоеприпасов, термобар с замедлением времени, таран.
- 9 типов целей: грузовик, БТР, танк, ЗСУ, ЗРК, вертолёт, дрон-перехватчик, склад ГСМ, РЛС.
  РЛС усиливает ПВО, склады ГСМ дают цепные взрывы.
- Тепловые ловушки уводят ракеты ЗРК, тепловизор подсвечивает технику ночью.
- Разрушаемый рельеф (воронки), обломки, дым, ударные волны, тряска камеры, вибрация телефона.
- Синтезированный звук через WebAudio, серии уничтожений с множителем очков, рекорд сохраняется.
- Управление: левая половина экрана — виртуальный стик, справа ОГОНЬ, ЛТЦ и выбор оружия.
  На компьютере: WASD/стрелки, пробел, 1–6, F, T, P.

## Файлы

- `game.html` — исходник страницы (без `<head>`), из него публикуется Artifact.
- `index.html` — собранный самостоятельный файл, **генерируется**: `python build.py`.

## Как сделать APK

Самый простой путь — обернуть `index.html` в WebView через Capacitor:

```bash
npm create @capacitor/app shahin   # положить index.html в www/
npx cap add android && npx cap open android   # собрать APK в Android Studio
```
